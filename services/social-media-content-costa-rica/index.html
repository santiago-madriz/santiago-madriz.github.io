Preguntas frecuentes

¿Qué podemos producir en una jornada?

Según la complejidad, podemos combinar fotografías, reels, clips y variaciones para distintas publicaciones.

¿El contenido se entrega listo para publicar?

Sí. Las piezas se exportan en las proporciones y especificaciones acordadas para cada plataforma.

¿Podemos trabajar de forma recurrente?

Sí. Se pueden planificar jornadas periódicas para mantener una biblioteca visual consistente.
